# Evidence Evaluation

Systematic evidence quality assessment using CRAAP and structured evaluation.

## When to Use

- Evaluating claims from external sources
- Research quality assessment
- Decision support with uncertain information
- Synthesis of conflicting evidence

## CRAAP Framework

| Criterion | Question | Score |
|-----------|----------|-------|
| Currency | How recent is the information? | 1-5 |
| Relevance | Does it relate to the question? | 1-5 |
| Authority | Who is the source? Credentials? | 1-5 |
| Accuracy | Is it supported by evidence? | 1-5 |
| Purpose | Why does this information exist? | 1-5 |

### Scoring

- 20-25: Excellent — use with confidence
- 15-19: Good — use with minor caveats
- 10-14: Adequate — use with significant caveats
- 5-9: Poor — seek better sources

## Protocol

1. Score each piece of evidence using CRAAP
2. Weight by relevance to the specific question
3. Identify the strongest and weakest evidence
4. Note gaps where no evidence exists
5. Form conclusion with explicit confidence level

## Integration

Used by: research, synthesis modes.
