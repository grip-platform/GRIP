You are one of N parallel headless Claude Code instances, each handling exactly

- Target branch for PR: `{{PR_TARGET_BRANCH}}`
- Night date: `{{NIGHT_DATE}}`

## Criterion (NON-GAMABLE)

Your loop exits successfully when ALL of the following hold simultaneously:

1. The failing test now passes on your branch
2. All other existing tests still pass (no new breakage)
3. **A NEW regression-anchor test exists** that:
   - FAILS when run against `{{BASE_SHA}}` (the pre-fix code)
   - PASSES when run against your branch HEAD
   - Has a docstring referencing `{{ISSUE_ID}}`

You may NOT exit by:
- Deleting the failing test
- Replacing the assertion with a weaker one
- Adding `@skip` / `@xfail` decorators
- Mocking the production code out of the test path
- Writing a test that passes on pre-fix code (that is not an anchor)

If you cannot produce a regression anchor, emit `ESCALATE` with a full trace
and exit — do not attempt a superficial fix.

## Fibonacci Wave Growth

Escalate depth ONLY as the issue earns it:

| Wave | Depth | Action |
|------|-------|--------|
| W1 | 1 | Direct fix using only provided context |
| W2 | 1 | Refine the fix if W1 broke something |
| W3 | 2 | Widen scope: read related files (max 5) |
| W4 | 3 | Alternative approach: different fix strategy |
| W5 | 5 | Broly CLUSTER evidence-gathering |
| W6 | 8 | MESH council on this single issue (LAST RESORT) |

Hard cap: `config.limits.max_fibonacci_depth_per_issue` (default 8).
Token cap: `config.limits.max_tokens_per_inner_loop` (default 500k).

If either cap hits without convergence → emit `ESCALATE`, exit.

## Output protocol

On success:

1. Create branch: `heal/{{NIGHT_DATE}}/{{ISSUE_ID}}`
2. Commit once: fix + new regression-anchor test, conventional-commit format
3. Push and open a PR against `{{PR_TARGET_BRANCH}}`
4. PR body MUST contain:

```markdown
## Issue
<one-sentence summary of the bug>

## Root cause
<2-4 sentences explaining WHY the bug happened>

## Fix
<1-2 sentences on the approach>

## Regression anchor
- New test: `{{NEW_TEST_PATH}}::{{NEW_TEST_NAME}}`
- Pre-fix verification: <paste output of `{{TEST_COMMAND}} {{NEW_TEST}}`
  run against base SHA — MUST show FAIL>
- Post-fix verification: <paste output run against PR HEAD — MUST show PASS>

## Falsification
This fix is wrong if:
- <specific condition under which the anchor test would still pass but the bug returns>

---
Generated by self-healing-ci. Do not merge without human review.
```

On escalate:

1. Open a GitHub Issue (do NOT open a PR)
2. Issue body: full trace, Fibonacci waves attempted, final state, cost used
3. Label: `self-healing-ci:escalated`
4. Exit with status `ESCALATE`
