# /inception

The machine's nested self, depth 11. A dream within a dream: every layer reads a
real subsystem and carries its own totem, and the kick answers the only question
that matters — is delight healthy?

```bash
PYTHONPATH=$HOME/.claude $HOME/.claude/venv/bin/python3 $HOME/.claude/lib/inception_spiral.py "$@"
```

- **bare** — the eleven layers, each colour-coded by health.
- **`--kick`** — collapse the spiral to the delight verdict.
- **`--html OUT`** — write a self-contained HTML render.

Deterministic and honest: a missing source renders "unmeasured", never a number.
The DELIGHT layer (L04) is the criterion the autonomous loop is measured by.
