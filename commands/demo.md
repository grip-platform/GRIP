# /demo Command

Quick access to demo mode features for live presentations.

## Usage

| Command | Action |
|---------|--------|
| `/demo` | Activate demo mode |
| `/demo agenda` | Show recommended demo flow |
| `/demo feature <name>` | Deep dive into specific feature |
| `/demo takeaway` | Generate PDF summary for audience |
| `/demo metrics` | Show productivity impact numbers |

## Features Available for Deep Dive

| Feature | Description |
|---------|-------------|
| `resurrection` | Session continuity via serialization |
| `efficiency` | Token savings protocols (30-35% budget) |
| `skills` | 95 skills overview and system |
| `confidence` | AskUserQuestion gates (99.9999999%) |
| `modes` | Operating modes system (25 modes) |
| `rsi` | Recursive self-improvement (Ralph loop) |
| `architecture` | Where files live, directory structure |
| `enforcement` | Tool substitution blocking (grep→rg) |

## Recommended Demo Flow

### Quick Demo (5 min)

1. Show resurrection: "I remember"

3. Show AskUserQuestion popup
4. Generate takeaway PDF

### Standard Demo (15 min)

1. Context refresh and resurrection
2. Efficiency protocols with live blocking

4. AskUserQuestion confidence gates

6. Q&A with audience

### Deep Dive (30+ min)

1. Full feature showcase
2. RSI loop with Ralph PR review
3. Architecture walkthrough
4. Custom skill creation
5. Interactive audience exploration
