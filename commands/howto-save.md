# /howto-save -- keep your work

**HOOK.** A `/clear` empties the window. GRIP's memory keeps what mattered.

**WORKED EXAMPLE.** Inside a session:

```
/save
/recall --quiet
```

`/save` writes the session's insights, state and context to GRIP's memory. `/recall --quiet` prints one line that names what GRIP remembers.

**### Your Turn.** Run `/save`. Then run `/recall --quiet`. **Completion gate:** the recall line is not empty.
