# /howto-start -- start GRIP

**HOOK.** A bare `claude` skips GRIP's launcher. The Pro settings then do not apply.

**WORKED EXAMPLE.** GRIP starts from the Terminal:

```bash
grip-tier pro
gg++
```

The first command prints `launch model: claude-sonnet-5-5` and `launch effort: medium`. The second prints a banner that starts with `GRIP · Pro plan (200K)`. Then Claude Code opens.

**### Your Turn.** Open Terminal. Type `gg++`. Press Enter. **Completion gate:** the banner appears, and the status line shows two rows under the prompt.

**COMPREHENSION CHECK:**

```
Reply A, B, or C:
  A) Any way to open Claude Code gives me the Pro settings
  B) Only gg++ applies the model pin, the effort level and the banner
  C) Not sure, show me again
```

(B is the move.)

**NEXT.** You can start GRIP. Next: talk instead of type, `/howto-talk`.

For a child: Type `gg++`. Press Enter. GRIP starts.
